--------------------------------------------------------
1. نظرة عامة
--------------------------------------------------------

Pazzle هي لغة برمجة مخصصة تُكتب في ملفات .pazzle
ثم يقوم البارسر بترجمتها إلى ملف .js وتشغيله تلقائياً.

طريقة التشغيل:
  pazzle myfile.pazzle

يمكن أيضاً تشغيل كل الملفات في المجلد الحالي:
  pazzle .

أو وضع البارسر في وضع المراقبة (يعيد الترجمة عند أي تغيير):
  pazzle -w

--------------------------------------------------------
2. التعليقات
--------------------------------------------------------

أي سطر يبدأ بـ # يُعتبر تعليقاً ويتم تجاهله.

مثال:
  # هذا تعليق
  make x = 10

ملاحظة: التعليقات تعمل فقط على سطر كامل، لا على نفس سطر الكود.

--------------------------------------------------------
3. المتغيرات
--------------------------------------------------------

لتعريف متغير قابل للتعديل، استخدم كلمة make:

  make name = "أحمد"
  make score = 0
  make total = 50

للحصول على عنصر HTML عن طريق الـ ID:
  make btn = get myButton

يُترجم إلى: let btn = document.getElementById("myButton");

--------------------------------------------------------
4. الثوابت
--------------------------------------------------------

لتعريف ثابت (لا يمكن تغييره لاحقاً)، استخدم كلمة stop:

  stop PI = 3.14159
  stop MAX = 100

للحصول على عنصر HTML كثابت:
  stop header = get pageHeader

إذا حاولت تعديل ثابت، سيعطيك البارسر خطأ.

--------------------------------------------------------
6. عمليات المتغيرات
--------------------------------------------------------

الصيغة العامة: متغير:عملية(قيمة)

--- العمليات الحسابية ---

  x:add(5)        ← x += 5
  x:subtract(3)   ← x -= 3
  x:multiply(2)   ← x *= 2
  x:divide(4)     ← x /= 4
  x:mod(3)        ← x %= 3
  x:power(2)      ← x **= 2
  x:set(10)       ← x = 10
  x:increment()   ← x++
  x:decrement()   ← x--
  x:toggle()      ← x = !x  (قلب القيمة المنطقية)

--- الإسناد الشرطي ---

  x:IfEmpty(0)    ← تعيين x إلى 0 إذا كان فارغاً أو null أو 0 أو false
  x:SetMax(100)   ← منع x من تجاوز 100
  x:SetMin(0)     ← منع x من النزول عن 0

--- عمليات DOM ---

  x:To(element)       ← element.innerText = x
  x:From(element)     ← x = element.innerText
  x:ToHTML(element)   ← element.innerHTML = x
  x:FromHTML(element) ← x = element.innerHTML
  x:ToValue(element)  ← element.value = x
  x:FromValue(element)← x = element.value

--- نقل قيمة (take) ---

  x:take(source, 5)
  ← ينقل 5 من source إلى x
  يُترجم إلى: x += 5; source -= 5;

--- تطبيق عملية على عدة متغيرات ---

  a, b, c:set(0)   ← يضع 0 في a و b و c معاً

7. الدوال
--------------------------------------------------------

لتعريف دالة استخدم catch، وأغلقها بـ }

  catch greet {
    local.My's.web.txtar(print("أهلاً!"))
  }

لاستدعاء الدالة:
  call greet()

الدوال تدعم داخلها:
  make, stop, return, call, print, عمليات المتغيرات, write, if

مثال مع return:
  catch calculateDouble {
    make result = x
    result:multiply(2)
    return result
  }

8. الشروط
--------------------------------------------------------

  if(score > 10){
    local.My's.web.txtar(print("ممتاز"))
  }else if(score equals 5){
    local.My's.web.txtar(print("جيد"))
  }else{
    local.My's.web.txtar(print("حاول مرة أخرى"))
  }

المقارنات بالكلمات الطبيعية:
  x equals 10        ← x === 10
  x not equals 0     ← x !== 0
  x greater than 5   ← x > 5
  x less than 100    ← x < 100

9. الحلقات
--------------------------------------------------------

--- حلقة تكرار بفاصل زمني ---

  loop_to.end.time({3}[{
    local.My's.web.txtar(print("تك"))
  }]

تُنفذ كل 3 ثواني. تُترجم إلى setInterval

--- حلقة for ---

  for i from 1 to 10 {
    local.My's.web.txtar(print(i))
  }

مع خطوة مخصصة:
  for i from 0 to 100 step 5 {
    local.My's.web.txtar(print(i))
  }

10. جملة match
--------------------------------------------------------

مثل switch/case في JavaScript:

  match color {
    "red" {
      local.My's.web.txtar(print("قف!"))
    }
    "green" {
      local.My's.web.txtar(print("تفضل!"))
    }
  }

ملاحظة مهمة: يجب تعريف المتغير color بـ make قبل استخدامه في match.

11. التعابير النمطية (Regex)
--------------------------------------------------------

الصيغة:
  myString = RE(النمط) to(متغير1, متغير2){
    ... كود داخلي ...
  }

مثال:
  myString = RE((word) (num)) to(firstName, age){
    local.My's.web.txtar(print(firstName))
  }

الأنماط المتاحة:
  (num)    ← أرقام (جشعة)
  (word)   ← أحرف وأرقام (جشعة)
  (any)    ← أي شيء (جشعة)
  (letter) ← حرف واحد
  (digit)  ← رقم واحد
  (numCL)  ← أرقام (كسولة)
  (wordCL) ← أحرف (كسولة)
  (anyCL)  ← أي شيء (كسول)
  (dot)    ← نقطة حرفية .
  (_)      ← مسافات بيضاء اختيارية
  (|)      ← رمز | حرفي
  b(       ← قوس ( حرفي
  b)       ← قوس ) حرفي

15. ربط ملف HTML
--------------------------------------------------------

لحقن الكود المُترجم داخل وسم <script> في ملف HTML:
  link index index.html

ملاحظة: ملف HTML يجب أن يحتوي على <script> و </script>
البارسر سيستبدل المحتوى بينهما بالكود المُترجم.

16. أمر run
--------------------------------------------------------

لتنفيذ أوامر Pazzle مباشرةً على نفس السطر:
  run x:add(1); local.My's.web.txtar(print(x))

يدعم: print، عمليات المتغيرات، call، write، read، if، for، match

--------------------------------------------------------
مثال شامل
--------------------------------------------------------

  fs
  make score = 0
  make name = "لاعب"
  stop MAX = 100

  catch updateScore {
    score:add(10)
    score:SetMax(MAX)
  }

  call updateScore()

  if(score equals 100){
    local.My's.web.txtar(print("وصلت للحد الأقصى!"))
  }else{
    local.My's.web.txtar(print(score))
  }

  for i from 1 to 5 {
    local.My's.web.txtar(print(i))
  }

  write("score.txt", score)
